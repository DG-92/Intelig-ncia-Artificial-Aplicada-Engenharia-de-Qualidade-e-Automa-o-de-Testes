# 📘 Glossário — IA Aplicada à Engenharia de Qualidade

---

# A

## API
Application Programming Interface. Interface que permite comunicação entre sistemas.

## Automação de Testes
Uso de ferramentas e scripts para execução automática de testes.

---

# C

## CI/CD
Continuous Integration / Continuous Delivery. Processo automatizado de integração e entrega contínua.

## Cypress
Framework moderno para automação de testes web.

---

# E

## Engenharia de Prompt
Técnica de elaboração de instruções para melhorar respostas de IA.

## E2E
End-to-End. Teste ponta a ponta que valida o fluxo completo da aplicação.

---

# I

## IA Generativa
Modelo de IA capaz de gerar conteúdo como textos, códigos, imagens e resumos.

---

# L

## LLM
Large Language Model. Modelo de linguagem treinado em grandes volumes de dados.

---

# M

## MFA
Multi-Factor Authentication. Método de autenticação utilizando múltiplos fatores de validação.

---

# O

## Observabilidade
Capacidade de monitorar e compreender o comportamento de sistemas através de logs, métricas e traces.

---

# P

## Performance Testing
Teste utilizado para validar estabilidade, escalabilidade e desempenho.

## Prompt
Instrução enviada para um modelo de IA.

---

# Q

## QA
Quality Assurance. Área responsável pela garantia da qualidade de software.

---

# R

## ROI
Return on Investment. Retorno sobre investimento.

---

# S

## Selenium
Framework de automação utilizado para testes web.

## Smoke Test
Teste rápido executado para validar funcionalidades críticas.

---

# T

## Teste de Contrato
Teste que valida comunicação e estrutura entre APIs e consumidores.

## Troubleshooting
Processo de investigação e resolução de problemas.

---

# 📚 Considerações

Este glossário foi construído durante os estudos no NotebookLM e consolidado como apoio para futuras revisões.
