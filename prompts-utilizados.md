# 🧠 Prompts Utilizados no NotebookLM

Este documento reúne os principais prompts utilizados durante os estudos sobre IA aplicada à Engenharia de Qualidade e Automação de Testes.

---

# 🎯 Objetivo

Explorar como a IA generativa pode apoiar:
- Criação de cenários de teste;
- Estratégias de QA;
- Automação;
- Análise de riscos;
- Documentação técnica.

---

# ✅ Prompt 1 — Criação de Cenários de Teste

## Prompt

```text
Crie cenários de teste funcionais, negativos e de borda para uma funcionalidade de login com autenticação MFA.
```

## Resultado Obtido

A IA gerou:
- Cenários positivos;
- Validação de token inválido;
- Expiração de sessão;
- Tentativas consecutivas;
- Fluxos alternativos.

## Insight

A resposta foi útil para testes funcionais, mas superficial em segurança.

---

# ✅ Prompt 2 — Estratégia de Testes

## Prompt

```text
Monte uma estratégia de testes para uma API REST crítica utilizada em produção.
```

## Resultado Obtido

A IA sugeriu:
- Testes funcionais;
- Contrato;
- Performance;
- Segurança;
- Monitoramento;
- CI/CD.

## Ajuste Aplicado

Foi necessário complementar com:

```text
Considere alta volumetria e múltiplas integrações.
```

## Prompt

# ✅ Prompt 5 — Engenharia de Prompt

## Prompt


A IA ajudou a:

# 🚀 Prompts Reutilizáveis

## Criação de Cenários

```text
Crie cenários positivos, negativos e de borda para a funcionalidade abaixo.
```

## Testes de API

```text
Monte testes para API REST considerando autenticação, contrato, carga e falhas.
```

## Estratégia de QA

```text
Crie uma estratégia de testes moderna considerando automação, CI/CD e observabilidade.
```

## Performance

```text
Quais testes de performance são recomendados para esta arquitetura?
```

---

# 📚 Aprendizados

- Prompts específicos geram respostas melhores;
- Contextualização técnica melhora precisão;
- IA funciona melhor como apoio analítico;
- Revisão humana continua essencial.
